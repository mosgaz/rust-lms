# Реестр архитектурных решений (ADR — Architectural Decision Records)

Любое отклонение от первоначального ТЗ, компромиссное инфраструктурное решение или жесткое ограничение фиксируется здесь AI-агентом или человеком.

## Формат имени

`[гггг.мм.дд]-[NNNN].md`, где:
- `гггг.мм.дд` — дата фиксации решения (не создания черновика);
- `NNNN` — четырёхзначный номер с ведущими нулями (`0001`, `0002`, …), следующий свободный.

Пример: `2026.09.28-0001.md`.

## Статусы

Поле `Статус` в шапке ADR принимает одно из значений:

| Статус | Значение |
|:---|:---|
| `Предложено` | Черновик, решение ещё не принято, обсуждается. |
| `Утверждено` | Решение принято и действует. |
| `Отклонено` | Решение рассмотрено и отклонено; сохранено для истории. |
| `Устарело` | Решение больше не применяется, но не заменено другим. |
| `Заменено ADR-NNNN` | Решение заменено новым ADR; ссылка обязательна. |

При смене статуса на `Заменено` — в новом ADR обязательно указывается `Заменяет: ADR-NNNN`, а в старом — `Заменено: ADR-NNNN` (с датой).

## Заменяет: <ADR-NNNN | —>
