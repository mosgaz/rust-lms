# Коммуникации

**Файл спецификации:** `specs/COMMUNICATIONS.md`

## Чаты
- **Личные** (1-to-1).
- **Групповые** (произвольные).
- **Чаты курса** (общий канал когорты).
- **Чаты домашнего задания** (привязаны к конкретному assignment).

Возможности: Markdown, вложения (файлы), голосовые сообщения, упоминания, реакции.

## Комментарии
Ветка обсуждений под каждым элементом контента (урок, задание, файл, тест) — по аналогии с Google Docs / GitHub. Поддержка резолва треда, упоминаний и уведомлений.

## Уведомления
Каналы:
- In-app;
- Email;
- Telegram;
- Webhook (для внешних систем тенанта);
- Push (PWA).

Правила маршрутизации уведомлений настраиваются на уровне тенанта и пользователя.
