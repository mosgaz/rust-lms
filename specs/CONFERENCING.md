# Видеоконференцсвязь (ВКС)

## Гибридный движок WebRTC
- **P2P (Mesh):** для занятий 1-to-1. Минимальная задержка, без промежуточного сервера.
- **SFU (Selective Forwarding Unit):** для групп. Кандидаты — Mediasoup / Janus. Сервер маршрутизирует потоки, экономя ресурсы клиентов.

## Инструменты
- Интерактивная доска (Whiteboard).
- Шеринг экрана.
- Совместный просмотр видео.
- Поднятие руки.
- Опросы в реальном времени.

## Закрытый контур
Для Air-gapped On-Premise разворачиваются локальные **TURN/STUN** серверы, работающие внутри LAN. Внешние STUN/TURN не используются.
