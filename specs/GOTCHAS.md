# Технические ловушки рантайма и сборки (Gotchas Log)

База знаний о скрытых особенностях стека, архитектурных барьерах и ошибках, на которые можно наступить повторно. Редактируется AI-агентами по факту обнаружения квирков (см. [`AGENTS.md`](AGENTS.md) §4).

Если ловушка привела к архитектурному решению — добавь ссылку на соответствующий ADR в [`decisions/`](decisions/).

## Зафиксированные ловушки

1. **WASM & Native OS код в Cargo Workspace:**
   * *Ловушка:* При случайном импорте крейта `api` в Leptos-фронтенд `client`, компилятор WASM упадёт с нечитаемой ошибкой о невозможности собрать системные вызовы типа `tokio::net::TcpStream` под таргет `wasm32`.
   * *Решение:* Фронтенд импортирует только плоские типы из `shared`. Любое сетевое взаимодействие с СУБД идёт строго асинхронно через Open API шлюз или через `#[server]` RPC-функции.
   * *Связанные правила:* [`STRUCTURE.md`](STRUCTURE.md) §4 (Dependency Rules), [`AGENTS.md`](AGENTS.md) §3.

2. **Ограничения WebAssembly памяти в Контуре Б плагинов:**
   * *Ловушка:* Динамически загружаемый WASM-плагин делит линейную память с Leptos. При выделении сырых буферов без использования методов `WasmMemoryBridge` очистка мусора браузера (GC) может пропустить этот сектор, что вызовет утечку RAM на вкладке.
   * *Решение:* См. правила [`CODING_STANDARDS.md`](CODING_STANDARDS.md) §3.3 по zero-copy аллокациям.
   * *Связанные правила:* [`PLUGIN.md`](PLUGIN.md) §2.2 (Контур Б), [`CODING_STANDARDS.md`](CODING_STANDARDS.md) §3.3.
