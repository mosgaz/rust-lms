# Технические ловушки рантайма и сборки (Gotchas Log)

База знаний о скрытых особенностях стека, архитектурных барьерах и ошибках, на которые можно наступить повторно. Редактируется AI-агентами по факту обнаружения квирков.

## Зафиксированные ловушки

1. **WASM & Native OS код в Cargo Workspace:**
   * *Ловушка:* При случайном импорте крейта `lms-database-db` в Leptos-фронтенд `lms-core-frontend`, компилятор WASM упадет с нечитаемой ошибкой о невозможности собрать системные вызовы типа `tokio::net::TcpStream` под таргет `wasm32`.
   * *Решение:* Фронтенд импортирует только плоские типы из `lms-shared-types`. Любое сетевое взаимодействие с СУБД идет строго асинхронно через Open API шлюз.

2. **Ограничения WebAssembly памяти в Контуре Б плагинов:**
   * *Ловушка:* Динамически загружаемый WASM-плагин делит линейную память с Leptos. При выделении сырых буферов без использования методов `WasmMemoryBridge` очистка мусора браузера (GC) может пропустить этот сектор, что вызовет утечку RAM на вкладке.
   * *Решение:* См. правила `CODING_STANDARDS.md` по zero-copy аллокациям.
